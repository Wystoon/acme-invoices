# AB#4821 · Export invoices as CSV
User Story · Active · Dana Novak · tags: export, invoices

## Acceptance criteria
1. GET /api/invoices/export.csv returns text/csv; charset=utf-8 with Content-Disposition: attachment; filename="invoices-<yyyyMMdd>.csv" (date from the injected TimeProvider).
2. Supports the same status and customerId filters as the list endpoint, plus optional from/to issue dates (inclusive).
3. Columns, in order: Number,Customer,IssueDate,DueDate,Currency,Total,Status. Dates yyyy-MM-dd, totals with invariant culture and 2 decimals.
4. Fields containing a comma, quote or newline are quoted per RFC 4180.
5. At most 10,000 rows. If more match, respond 422 with a problem-details message.
6. Covered by integration tests.

## Description
As a finance clerk
I want to download the invoice list as a CSV file
so that I can reconcile invoices in my spreadsheet at month-end close.

Today Finance copies the invoice table from the UI page by page. That takes about two hours at every month-end close and is error-prone (screenshot from Mira below).
[image]

Scope: backend endpoint only. The export button in the UI is a separate story under Invoice UI refresh.
Use the same filters as the invoice list (GET /api/invoices).
